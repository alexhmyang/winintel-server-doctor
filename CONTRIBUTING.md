# Contributing

Author: 数萌AI服务器 (winintel) | winintel.com

Welcome Ubuntu compatibility fixes, customer hardware profiles with clear baselines, report improvements and integrations of maintained open-source tools.

Explain hardware/OS, exact reproduction commands and expected vs observed behavior. Do not include credentials, private customer reports, serial numbers or proprietary data. Keep upstream headers/licenses. AI-assisted changes should be disclosed and reviewed by the submitting human.

Run the standard-library behavioral tests and Bash syntax checks before submitting. Changes affecting driver/toolkit installation need a native Ubuntu validation record; CI syntax/unit checks alone do not prove a clean installation.

Keep disk tests restricted to unique scratch files and keep UNKNOWN explicit. Do not turn untested checks into PASS.
